# Reino de Valdemar — 1.4.0
Juego de estrategia medieval 3D creado desde cero con Three.js, Vite y Electron.

## Ejecutar
- Node.js 20 o superior
- `npm install`
- `npm run start` para jugar en navegador
- `npm run desktop` para la ventana Electron (con Vite ejecutándose)
- `npm run dist` para compilar un ejecutable portable de Windows

## Controles
- Clic izquierdo sobre el terreno para colocar la construcción elegida.
- Clic derecho y arrastrar para desplazar la cámara.
- Usa el panel del consejo para elegir edificios.
- Guardar conserva los recursos y el progreso básico en el equipo.

## Estado
Prototipo jugable en desarrollo. Incluye terreno procedural, bosque, río, castillo, aldeanos animados, menú, opciones gráficas, economía básica y colocación de edificios. Los modelos actuales son geometría procedural; no se anuncian paquetes externos que aún no estén integrados.
